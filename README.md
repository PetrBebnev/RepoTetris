# 🎮 Тетрис на чистом JavaScript

Классическая игра «Тетрис», реализованная на чистых HTML, CSS и JavaScript
без использования сторонних библиотек и фреймворков. Всё помещается в один
файл `index.html` — открыл в браузере и играешь.

## 📖 Описание

Проект представляет собой полноценную версию культовой головоломки: падающие
фигуры из четырёх блоков нужно складывать в горизонтальные линии, чтобы они
исчезали и приносили очки. Реализованы все ключевые механики — поворот фигур,
ускоренное и мгновенное падение, предпросмотр следующей фигуры, подсчёт очков,
пауза и перезапуск игры.

## 🚀 Как запустить

**Способ 1 — просто открыть файл:**

1. Скачай файл `index.html` (или `tetris.html`) из этого репозитория.
2. Дважды кликни по нему — игра откроется в браузере.

**Способ 2 — через GitHub Pages (онлайн):**

1. Зайди в репозиторий → **Settings** → **Pages**.
2. В разделе **Branch** выбери `main` и папку `/ (root)`, нажми **Save**.
3. Через минуту игра будет доступна по адресу:
   `https://<твой-username>.github.io/<имя-репозитория>/`
